# Changelog

## Cadova for VS Code 1.0.0

The first release.

## Additions

- Generate and Preview actions above every `Model`, `Group` and `Project` in Swift files that import Cadova. They generate just that model, or the models in that group or project, and Preview opens each model it generates.
- A 3D preview for 3MF files that reloads whenever the file changes, and regenerates the models it shows when a Swift file in their package is saved.
- Cadova Viewer's view controls in the preview: perspective and orthographic projection, the standard views, with a picture of each when hovering its button, and options for materials, smooth shading, edges, the grid, the origin and axis directions.
- A parts list in the sidebar, with thumbnails, for showing, hiding and finding a model's parts.
- Measuring, with snapping to corners and along axes, and a list of measurements in the sidebar.
- Up to eight cross-sections, moved and turned with a gizmo, with cut faces filled in each part's color.
- An Info panel with the model's size, volume, area, counts and metadata.
- Slice, which opens the model in your slicer, offering the slicers it finds the first time.
